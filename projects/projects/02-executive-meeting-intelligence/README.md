# 02 — Executive Meeting Intelligence

**Platform:** Make.com, Microsoft SharePoint, OpenAI, Microsoft Teams  
**Status:** Workplace implementation / portfolio documentation in progress

## Overview

A workflow designed to reduce the manual work involved in turning senior leadership meeting transcripts into structured management reports.

The implementation used meeting transcripts stored in SharePoint, AI-assisted analysis and automated delivery of the resulting report into Microsoft Teams.

## Business Problem

Leadership meetings produce useful discussions, decisions, issues and actions, but manually reviewing transcripts and preparing structured reports takes time.

The workflow was designed to automate much of that information-processing process while keeping the final output available for human review.

## Workflow

```text
Meeting Transcript
        ↓
SharePoint
